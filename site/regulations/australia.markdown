# Australia

No Remote ID mandate is in force in Australia, and none is scheduled with a firm
date. This page summarizes the current, pre-decisional state of play rather than a
finalized technical requirement.

## Status

- The Australian Government's drone policy programme (the umbrella site for CASA
  policy) is still at "next steps" / Policy Impact Analysis stage, not rulemaking.
- A discussion paper (not a proposed rule) circulated for public consultation in
  June–July 2023. The 2024 Aviation White Paper only "reiterated CASA's intention"
  and committed to a further Policy Impact Analysis — still pre-decisional as of
  this writing.
- A secondary source (Transport Canada's own regulatory proposal, see the
  [Canada](/regulations/canada/) page) characterizes Australia's intent as
  "tentatively for 2030" — this figure does not appear on any Australian primary
  source found during this research.

## Anticipated approach

The 2023 discussion paper is explicit that any future mandate would draw on **ASTM
F3411-19 and ASD-STAN prEN 4709-002** — the same wire format DRIFT implements — and
frames the policy choice as Broadcast Remote ID vs. Network Remote ID vs. ADS-B,
explicitly ruling out ADS-B due to frequency congestion.

{: .note }
> A separate "Drone Security Reform" consultation (opened 2026-04-24, run by Home
> Affairs, not CASA) touches "electronic identification"/"electronic conspicuity"
> but is a counter-drone security policy exercise, not a CASA airworthiness/
> broadcast-RID rulemaking — don't conflate the two.
