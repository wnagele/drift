# Drone Remote Identification and Flight Tracking
This project supports DRI (Drone Remote Identification) as required by some countries 
in their airspace.

DRIFT turns the MAVLink telemetry your flight controller already produces into
Remote ID broadcasts — on Bluetooth 4, Bluetooth 5 Long Range, Wi-Fi Beacon and
(optionally) Wi-Fi NAN — and serves a web dashboard for status and configuration
over its own WiFi access point.

1. [Installation](/installation/) — wire, flash and configure a module.
2. [Broadcasting](/broadcasting/) — the transports, their defaults and receiver compatibility.
